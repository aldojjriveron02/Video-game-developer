# Vertical Slice — Gate Zero Spec (Round 114)
**Hypothesis:** one final-quality mission proves the Mecha Protocol production pipeline.

## 5 questions (pass/fail defined BEFORE building)
1. **Fun after novelty?** (Aldo's playtest: "is it fun?" — measurable per BUILD-PLAN.md)
2. **Content velocity?** (second mission encounter faster than first — else pipeline FAILED)
3. **Performance?** (iPhone 17 + desktop; 60fps; <100ms input)
4. **Unit cost?** (build-hour log → total estimate × 1.3 margin)
5. **Delivery?** (itch.io web build, zero backend)

## Risk register (failure statements)
- If second mission takes ≥ first → pipeline FAILED.
- If combat not fun at final quality → KILL.
- If unit cost × 2 × 1.3 > runway → RESCOPE or KILL.
- If iPhone perf < 60fps → fix or cut scope.

## Not in slice
- Missions 2–3, full hangar, Commander Edition, Steam.

## 75-20-5 quality tiering
- **5% peaks (max):** per-limb damage feedback, heat chevrons, combat responsiveness, pilot barks.
- **75% valleys (good-enough):** hangar UI, menus, non-slice systems.
- **20% good:** everything else.

## Gate verdict (week 8-10)
- **GREEN:** all 5 answered, no apologies → greenlight production.
- **YELLOW:** 1-2 weak → pause, fix, re-gate.
- **RED:** core assumption failed → cancel (cheapest option).
- Greenlight / pause / cancel are EQUAL outcomes.

## Rules
- Sustainable solo pace (no hero mode — invalidates velocity).
- Build-hour log from day 1.
- Stop polishing when 5 questions answerable.
