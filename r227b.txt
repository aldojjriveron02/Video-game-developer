From abratabia's iOS Safari gotchas: touchcancel must be handled — it fires when a system gesture steals the touch; double-tap zoom and the three-hundred-millisecond tap delay must be neutralized; WebGL context-loss must be handled; localStorage subject to tracking-prevention seven-day eviction. The techniques — freeze-safe mobile polish, only low-risk additive. Viewport meta with width device-width, initial-scale one, maximum-scale one, user-scalable no. Canvas sizing: create in JS, size from innerWidth and innerHeight, multiply by devicePixelRatio capped at two — above two hurts perf with zero visual gain; CSS at one-hundred percent; listen to resize plus orientationchange. Touch input: pointer events, not mouse events; preventDefault to stop scroll and zoom; track each touch by pointerId in a Map for multi-touch. Conflict discipline: touch-action none on game controls ONLY — not globally — so comments, search, and inputs on the itch page still work. Browser chrome: pad UI with env safe-area insets; use dvh units instead of one-hundred-vh. Audio: no autoplay before gesture; create the context early; resume on first tap; re-check suspended state and resume on every input. Perf: requestAnimationFrame only, never setInterval for the loop; batch Canvas2D draws; watch memory — a twenty-forty-eight squared RGBA texture is sixteen megabytes; flag any frame over sixteen milliseconds. Coordinate correctness: convert client and touch coordinates to canvas space after every resize. What to avoid — the mobile freeze traps. Adding mobile FEATURES during the freeze window — post-deadline edits are bug-fixes-only, so a half-finished mobile feature is a liability. Relying on the Fullscreen API on iOS Safari — not available in browser, PWA only. Relying on screen orientation lock — not supported in Safari outside standalone PWAs; use a rotate-prompt div. The one-hundred-vh bug — mobile browser chrome makes it wrong; use dvh or innerHeight. Global touch-action none or global preventDefault — breaks page inputs and comments on the itch page. Unresumed AudioContext — silent game equals broken game. iOS memory strictness and WebGL canvas resize leaks. Ignoring touchcancel — touches stolen by system gestures leave controls stuck "on." localStorage fragility.
