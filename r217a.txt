Validation — the itch round-trip probe specifics. itch.io runs HTML5 games in an iframe on a different domain than the game page; embed options are "Embed in page" and "Click to launch in fullscreen"; mobile forces fullscreen launch. This iframe placement is where saves die. aaryte's Fracas Three devlog: "if you block third-party cookies in Chrome, HTML5 games hosted on itch.io are denied access to LocalStorage and SessionStorage, even though it still works if you're testing using localhost" — they shipped workarounds and a warning. Safari on iPad and iPhone: "Prevent cross-site tracking" breaks localStorage for itch HTML5 games because the frame is cross-domain. Andrew Plotkin on intfiction: Safari "loses the localStorage for the embedded frame as soon as you quit — not after seven days... You can avoid this particular problem by loading the iframe URL directly." Same thread: Safari keeps localStorage seven days max. The authoritative mechanism: MDN State Partitioning — "accessible storage is partitioned by top-level site"; the Storage Access API exists so cross-site iframe content can request unpartitioned storage; Chrome rolled this out from version one-fifteen.
