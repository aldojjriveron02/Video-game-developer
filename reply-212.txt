The techniques — last-mile polish. Gongylus's Brackeys jam devlog: substituted an audio knocking cue with a visual UI element via a main-menu toggle — jam-cheap, directly applicable to any audio telegraph. Reused an existing forced-movement script to add point-and-click alongside WASD, then touchscreen — build alternates from systems you already have, not new input stacks. The curb-cut insight: the hard-of-hearing visual UI would have helped everyone, so consider making assist cues standard rather than toggle-gated. HyperDot's changelog techniques: button remapping, clearer onboarding, published codex, compatible-device list, brighter highlights, text legibility pass, dark high-contrast variant, stop-background-animation, disable-screenshake; input coverage from Xbox Adaptive Controller to eye-tracking to touch. What to avoid. The Wolverine trap from last month: Insomniac's hotfix adjusted the scent trail and audio indicator after backlash; less intense indicators are harder to see for low-vision players. Lesson: never weaken an accessibility cue to satisfy feedback — make intensity toggleable instead, and regression-check every patch. Settings wipe on update — re-verify toggles persist across our versioned-save migration. Skipping validation on patches — jam-week hotfixes are the highest-risk window. Jam traps: new content without the a11y equivalent; touch fixes untested on desktop and vice versa; page text drifting from in-game reality.
