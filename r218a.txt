Full report is in your Drive. The jam mobile findings. LD60 confirmed: theme reveal Friday October sixteenth at six PM Eastern, seventy-two-hour window. itch.io is the canonical LD web host. Official itch HTML5 docs: on mobile, itch ALWAYS forces "Click to launch in fullscreen" regardless of desktop embed settings; there is a dedicated "Mobile Friendly" project flag, and if it is NOT enabled, mobile visitors see a warning that the game may not work. Critical packaging detail from itch founder leafo: "the aspect ratio of your embed is used to set the orientation of the device" — the embed's width-by-height ratio steers portrait versus landscape on phones, and mobile games always launch fullscreen. Packaging hard constraints: ZIP only; index.html at the ZIP root; max one thousand files; filenames under two-forty characters; extracted under five hundred megabytes; single file under two hundred; the game is hosted on a subdirectory of itch's HTML CDN — ABSOLUTE paths break, use relative paths; filenames are case-sensitive; external resources must be HTTPS. Validation — the four-item gate. Gate one: submission-pipeline dry run. Thompson's LD guide: the hour where things go most wrong is submission hour — aim to finish two hours before the deadline; prepare icon, screenshots, gameplay video in that buffer; warm up by submitting a throwaway build beforehand so the pipeline is practiced, not learned at two AM. Gate two: itch project config check — Mobile Friendly ON, embed aspect ratio matching the designed orientation per leafo's rule, viewport dimensions set, test both "launch from game page" AND the direct html dot itch dot zone URL paths. Gate three: real-device validation on iPhone seventeen with Safari — audio unlock on first real tap, forced-fullscreen launch from the itch game page not just the direct URL, rotation, background and foreground bfcache resync, incoming-call interruption, silent-switch state.
