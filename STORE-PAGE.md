## Description draft
**Build your mechs. Command the grid. Survive 3 missions.**

Mecha Protocol is a free turn-based tactics game for your browser. Build a lance of 3 mechs in the hangar, then fight grid battles where every limb matters — blow off an arm and that weapon is gone.

**Features**
- 3 hand-designed missions + a rival ace pilot (VEX) with a phase-2 enrage
- Hangar mech-building: chassis, armor, arm weapons, live paper-doll rebuilds, shareable build codes
- 3v3 grid combat with per-limb damage, heat management, and visible enemy intent
- Pilot barks, mission briefings, undo system, difficulty modes
- Plays on iPhone and desktop — touch or mouse, no install

**Controls:** tap/click to select, move, and attack. Full help screen in-game (press ?).

**Status:** prototype — the core loop is complete and playable end to end. More missions, mechs, and a daily challenge are on the roadmap.

**Credits:** solo dev + AI assistant. Music: Pixabay (see in-game credits). Made with vanilla JS — no engine.
