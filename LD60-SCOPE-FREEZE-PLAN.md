# Ludum Dare 60 — Scope-Freeze Plan
**Game:** Mecha Protocol · **Prepared:** Oct 14, 2026
**Rule:** scope freezes Friday night. Saturday and Sunday are execution, not design.

## LOCKED Friday night (no changes after ~10PM EDT Fri)
- Core mechanics: grid size, turn structure, action points, movement, attack resolution.
- Per-limb damage model: limb HP, destruction effects, targeting.
- Heat system: generation, dissipation, chevrons, 70% alarm, overload.
- Intent telegraphs: display, threat magnitude, persistence, pitch stinger.
- Hangar: parts, weapons, heat budget, valid-only filter, recipes.
- Difficulty: failure ratchet, miss pity, 4 assists, 0.5s delay, single-tap.
- 3-mission structure and the M3 VEX duel as the climax.
- Save/telemetry/consent systems.
- **No new systems.** If it's not in the build Friday night, it doesn't exist.

## FLEX (can change Sat–Sun)
- All narrative text: briefings, barks, taunts, mission titles, faction names.
- Visual skin: palette, background art, mech silhouette tweaks (no new rigs).
- Audio: music track selection, bark delivery tone.
- Balance numbers: damage, HP, heat values (tuning, not redesign).
- Bug fixes: anything broken gets fixed. Broken > theme.
- Screenshots, GIFs, jam page copy.

## Explicitly OUT for the jam
- Multiplayer / async / leaderboards (server scope — not in 72h).
- New weapons, new mechs, new missions (content freeze).
- Full voice acting (barks are text; keep it that way).
- The vertical-slice production pipeline (that's the long game; the jam is a detour, not a replacement).
- Any feature that needs Aldo's input and he hasn't given it (faction names default to placeholders if TBD).

## Contingency
- **Theme is hostile** (can't fit tactics): pick the closest archetype response, commit in 2h, don't rethink.
- **Build breaks Saturday:** revert to Friday-night build. A working submission beats a broken ambitious one.
- **Aldo unreachable Friday 6PM:** El Loko makes the theme call solo. Report the decision; don't wait.
- **Real life intervenes:** minimum viable submission = Friday build + theme text pass + jam page. That's submittable.

## Monday submission order
1. Final playtest (incognito, iPhone + desktop) — 1h.
2. Package static build — 30min.
3. Upload + jam page (writeup, screenshots, source link) — 1h.
4. Submit before 6PM EDT. Buffer: aim for 3PM.
