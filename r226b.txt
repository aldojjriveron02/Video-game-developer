Failure-mode tests: QuotaExceededError to graceful failure plus a user-facing message; corrupted import to clean rejection, never crash; unknown schema version to refuse or migrate, never silently load; type-check every field, clamp numbers, fall back to defaults. Lifecycle save test: tab close mid-write must leave the previous save intact; use pagehide and visibilitychange plus beforeunload — mobile Safari beforeunload is unreliable. Device-matrix test: run the whole checklist in the actual itch iframe embed AND on iOS Safari. The techniques — freeze-safe save polish. Single serializable state object plus saveVersion, plain JSON only; derive transient state instead of storing it. Throttled autosave: mark state dirty when it changes, poll every thousand milliseconds and write only if dirty; shipped datum — Cookie Clicker autosaves every sixty seconds plus a manual Save button. Export and import: JSON to Base64 string the player copies or downloads; Cookie Clicker's shipped ExportSave uses a prompt with a textarea, and its loader always Base64-decodes. Checksum: store a CRC32 over the serialized data alongside it; on load, detect corruption before parsing; on mismatch, clear message plus offer previous backup or fresh start — "silent failure is the outcome to avoid above all else." Backup rotation: keep one previous generation; rotate only after the new save's checksum verifies — the browser analog is writing the backup key first, then overwriting the live key. Save indicator UI: show "Saving," "Saved," "Save failed" so the player knows persistence state. Graceful degradation wrapper: 2048's shipped LocalStorageManager probes with a try-catch test-write and falls back to an in-memory fake storage so the game never hard-crashes when storage is denied; never call localStorage dot clear since it wipes unrelated keys. What to avoid — the save freeze traps. Post-freeze schema drift. localStorage-only in the itch iframe — browsers may clear it without warning; private mode is a zero-quota trap. Cross-origin iframe SecurityError in Safari. Quota traps — about five megabytes per origin on iOS.
