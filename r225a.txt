Perf "freeze" for a jam means two things locked simultaneously: the frame budget verified and held on the SHIP build, and no code changes that can move perf numbers allowed after a cutoff. Game Developer's LD submission advice: target completion about two hours before the deadline and build and ship early and often — upload a warmup game first so submission mechanics are rehearsed. The Generalist Programmer's game-jam guide recommends a feature-freeze deadline typically twelve to eighteen hours before submission: after it, no new features — only bug fixes and polish. For our slice the perf freeze should be stricter than the feature freeze: nothing that changes draw calls, allocations, or the audio graph after the perf lock. And the cautionary tale — Vampire Survivors shipped in Phaser 3 as browser tech, then migrated to Unity in twenty-twenty-two to improve performance as scale exploded. Web tech ships hits, but the perf ceiling is real — know it BEFORE the jam, not during ratings. Validation — the final perf checklist with numbers. The web.dev RAIL model: at sixty fps the absolute frame ceiling is sixteen-point-seven milliseconds, but browsers need about six to render, so the guideline is to produce each frame in ten milliseconds or less. At one-twenty hertz the ceiling is eight-point-three — the number our part-ten audit must be re-measured against on the final build. Input response: RAIL says respond within one hundred milliseconds, budget fifty for actual input handling. Tooling for the final pass: Chrome DevTools CPU throttling, FPS meter, Performance Monitor for CPU, heap, DOM nodes, layouts per second. And the critical rule from nixiefx's mobile performance guide: profile on a REAL device via chrome inspect or Safari's Develop menu, and "never shrink features to fake the numbers" — re-measure the real game, don't stub systems out. The console-grade analog from Game Programming Patterns' Object Pool chapter: console manufacturers require soak tests — running the game unattended in demo mode for extended periods.
